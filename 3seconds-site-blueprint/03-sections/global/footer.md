# Section — Footer

## Goal
End with brand confidence, not a legal dump.

## Layout
- Giant `3seconds` or `MAKE THE NEXT 3 COUNT.` wordmark line
- email/contact
- nav columns
- social links
- location/timezone if useful
- privacy/terms
- copyright

## Interaction
Optional giant arrow or frame that subtly follows pointer movement on desktop.

## Motion
Footer arrives mostly static; after a motion-heavy page, the ending should feel settled.
