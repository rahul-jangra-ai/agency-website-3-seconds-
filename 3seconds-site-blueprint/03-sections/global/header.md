# Section — Global Header

## Purpose
Persistent orientation with minimum visual weight.

## Desktop
- Left: 3seconds wordmark
- Right: Work, Services, About, Contact
- Primary CTA: Start a brief
- Optional menu trigger only if secondary links require it

## Behavior
- Transparent over hero if contrast is safe.
- After 40–80px scroll, transition to a compact solid/blurred shell.
- Hide slightly on downward scroll; reveal on upward scroll. Never hide when keyboard focus is inside.

## Acceptance criteria
- Header always has sufficient contrast.
- Current route is conveyed beyond color alone.
- Mobile controls meet 44px touch target.
