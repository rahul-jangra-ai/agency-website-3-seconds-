# Contact Section — Project Brief Form

## Interaction model
Single-page form with progressive visual grouping, not a multi-step wizard unless there are 8+ required fields.

## Field order
1. Name
2. Work email
3. Company
4. What do you need? multi-select
5. Project summary
6. Budget range (optional)
7. Launch timing (optional)

## UX
- labels always visible;
- inline validation after blur/submit;
- preserve values after validation errors;
- submit state shows progress;
- success state explains expected response window only if the team can honor it.
