# Home Section — Selected Work Reel

## Purpose
Move from promise to proof immediately.

## Content
3–5 strongest projects.

## Desktop interaction
Option A (preferred): vertical scroll drives a horizontal rail of oversized project frames.
Each frame shows client, project, service tag, and year.
Hover/tap can play a 2–4s loop.

## Mobile
Normal vertical stack of large 4:5 cards. No forced horizontal scroll-jacking.

## Acceptance criteria
- Project title is always visible; not hover-only.
- Every project links to a case study or detail destination.
