# Work Section — Project Grid

## Desktop rhythm
Use a designed repeating rhythm rather than random masonry:
- large landscape;
- portrait pair;
- full-width feature;
- 2-column cards.

## Cards
Title and tags remain outside or over a safe contrast panel.

## Hover
Image scale <=1.03; title arrow moves; optional preview loop starts. Avoid dramatic cursor-chasing transformations.

## Loading
Progressively load images below the fold; reserve aspect-ratio boxes.
