# Animation Acceptance Tests

For every animated section, verify:

- [ ] Content is readable before/without JavaScript animation.
- [ ] Reduced-motion variant is usable and visually intentional.
- [ ] No horizontal overflow at 320px width.
- [ ] Scrolling remains responsive during animation.
- [ ] Animation does not block clicks/taps.
- [ ] Focused controls remain visible.
- [ ] Video has poster/fallback.
- [ ] No giant cumulative layout shift when media loads.
- [ ] Sticky section releases reliably.
- [ ] Browser back/forward navigation restores sensible scroll behavior.
- [ ] Route transition cannot leave an overlay stuck on screen.
