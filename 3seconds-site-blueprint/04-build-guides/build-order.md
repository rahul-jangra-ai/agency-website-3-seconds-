# Recommended Build Order

## Phase 1 — System
1. Route shell
2. Font loading
3. Color/type/spacing tokens
4. Grid/container utilities
5. Header/footer
6. MediaFrame + VideoLoop
7. AnimatedHeading + reduced-motion utilities

## Phase 2 — Home vertical slice
1. Hero
2. One project card
3. Final CTA
4. Mobile pass
5. Performance pass

## Phase 3 — Portfolio
1. Work index
2. Project filtering
3. Case study template
4. Gallery/results/next project

## Phase 4 — Capability + trust
1. Services
2. About
3. Client proof

## Phase 5 — Conversion
1. Contact form + backend
2. Form validation / success / failure
3. Careers
4. 404

## Phase 6 — Polish
1. Page transitions
2. Hover previews
3. marquees/parallax/sticky sequences
4. analytics events
5. SEO/social cards
6. accessibility audit
7. Lighthouse / real-device performance audit

## Important
Build motion last enough that content/layout is stable, but prototype the hero motion early enough to validate the art direction.
