# Asset & Shot List

## Home showreel
Create a 12–20 second silent-first edit with:
- 8–15 strongest project shots;
- mix of close-up / wide / typography / product / social frames;
- fast first 3 seconds;
- clean loop point;
- no essential message dependent on audio.

Export:
- desktop landscape;
- mobile portrait/4:5 cut;
- poster JPG/AVIF;
- compressed WebM + MP4 fallback.

## Team/culture
Capture:
- editorial team portrait;
- 10–20 candid stills;
- 5–8 tiny 2–4s BTS loops;
- hands, screens, shoots, sketches, edit timeline, set details.

## Case study package per project
- hero loop;
- 2 landscape key visuals;
- 2 portrait/social assets;
- 1 process/BTS visual;
- result graphic / metric frame;
- optional client quote portrait/logo.
