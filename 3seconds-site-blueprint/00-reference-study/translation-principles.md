# Reference → 3seconds Translation Principles

| Reference pattern | Keep the principle | Make it original for 3seconds |
|---|---|---|
| Huge editorial headline | Typography as a visual object | Countdown / attention language; condensed display type; variable scale |
| Culture-heavy hero art | Show creative personality instantly | Fast-cut showreel + typographic "3 / 2 / 1" framing |
| Long narrative home | Build trust progressively | Hook → work → capabilities → process → proof → people → CTA |
| Image-heavy work index | Portfolio is the product | Motion thumbnails, hover scrub, filter chips, editorial grid |
| Big numeric proof | Quantify credibility | Real campaign metrics only; animated typography |
| Repeated services | Consistent information model | Sticky service index + expandable chapters |
| Logo/client sections | Social proof | Monochrome partner ticker + select client wall |
| Playful tone | Avoid generic agency language | Short, confident, culturally aware microcopy |

## 3seconds north star
A visitor should understand three things in under three seconds:
1. This is a creative media agency.
2. The work feels contemporary and high craft.
3. There is an obvious next action: **See the work** or **Start a brief**.
