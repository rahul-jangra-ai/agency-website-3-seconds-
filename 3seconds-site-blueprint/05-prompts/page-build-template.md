# Prompt Template — Build a Page

Paste this after `master-build-prompt.md`.

---

Build the route described in the attached page spec and section specs.

Before implementation:
1. list required components;
2. identify reusable components that already exist;
3. define the content/data schema;
4. describe desktop/tablet/mobile layout differences;
5. describe motion triggers and reduced-motion fallbacks;
6. identify any missing real assets/data and use placeholders instead of invention.

Then implement in small coherent components. Keep animations scoped and clean up observers/listeners. Add metadata for the route. Finish by checking every acceptance criterion from the supplied specs.

Do not redesign unspecified global tokens without calling out the change.
---
