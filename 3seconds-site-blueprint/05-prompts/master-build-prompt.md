# Prompt — Master Build Context for Gemini

Use this as a reusable preface, then append the relevant page/section spec.

---

You are building the 3seconds creative media agency website. Treat the supplied Markdown specifications as the product requirements and source of truth.

Core brand idea: attention is won or lost in the first three seconds. The site must feel fast, editorial, visual, and crafted, while remaining accessible and performant.

Rules:
1. Do not copy Creativefuel or any reference site's code, exact layout, text, or assets.
2. Do not invent real clients, metrics, testimonials, awards, addresses, or team facts. Use obvious placeholders when data is missing.
3. Keep semantic HTML and keyboard access intact even when layouts are experimental.
4. Honor `prefers-reduced-motion`.
5. Use optimized media and reserve dimensions to avoid layout shift.
6. Keep DOM reading order logical.
7. Before coding, summarize the component tree, data needs, responsive behavior, and animation states.
8. After coding, report which acceptance criteria are satisfied and any remaining gaps.

Design language: Ink/Paper neutral shell, Signal orange accent, very sparing Flash lime, oversized grotesk display typography, editorial grid, square media, timecode/countdown motifs.

Motion language: fast, purposeful, transform/opacity-based, no blocking intro, no scroll-jacking on mobile, no essential hover-only content.
